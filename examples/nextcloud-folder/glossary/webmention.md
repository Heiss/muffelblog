A webmention is a message from one website to another. The sending site says:
"my page _source_ links to your page _target_". The receiving site fetches the
source, checks that the link is there, and can then show it as a reply, like or
mention.

It is an open standard of the W3C, so it works between different kinds of
sites without a central service.
