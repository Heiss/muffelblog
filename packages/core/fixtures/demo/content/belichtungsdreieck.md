Drei Einstellungen bestimmen, wie hell ein Foto wird: die Blende, die Belichtungszeit und der ISO-Wert. Jede Stufe verdoppelt oder halbiert die Lichtmenge. Von f/2,8 auf f/4 zu gehen halbiert das Licht, von 1/125 s auf 1/60 s verdoppelt es, von ISO 100 auf ISO 200 verdoppelt es die Verstärkung.

Entscheidend sind die Nebenwirkungen:

| Einstellung     | Nebenwirkung                                                 |
| --------------- | ------------------------------------------------------------ |
| Blende          | Schärfentiefe: weit offen ist wenig scharf, geschlossen viel |
| Belichtungszeit | Bewegung: kurz friert ein, lang verwischt                    |
| ISO             | Bildrauschen: höhere Werte rauschen stärker                  |

![Schema: Blende, Zeit und ISO im Gleichgewicht](bilder/blende-zeit-iso.jpg)

Ein Beispiel: Für Nebel im Park nehme ich f/2,8, 1/250 s und ISO 100. Das Licht reicht, das Bild bleibt sauber, und die Hintergrundunschärfe hebt das Motiv ab.
