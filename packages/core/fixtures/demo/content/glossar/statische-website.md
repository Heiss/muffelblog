description: 'Eine Website aus fertigen Dateien, die ohne Datenbank und ohne Code auf dem Server ausgeliefert wird.'
---

Eine statische Website besteht aus fertigen HTML-, CSS- und Bilddateien. Der Server liest sie nur von der Platte und liefert sie aus. Änderungen entstehen vorher in einem Build, nicht erst beim Aufruf.
