tags: [fotografie, glossar]
description: 'Die verstellbare Öffnung im Objektiv, die bestimmt, wie viel Licht auf den Sensor fällt; sie wird als f-Zahl angegeben.'
---

Je kleiner die f-Zahl, desto weiter ist die Blende geöffnet und desto mehr Licht trifft den Sensor. Eine große Öffnung ergibt eine geringe Schärfentiefe, eine kleine Öffnung eine große.
